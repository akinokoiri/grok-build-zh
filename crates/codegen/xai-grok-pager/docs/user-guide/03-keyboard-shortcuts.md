# 键盘快捷键

Grok Build TUI 内置快捷键（当前不可自定义重映射）。

## 输入模式

- **简易模式（默认）**：方向键导航，`Shift+方向` 跳转回合，`Space` 聚焦输入，字母键自动聚焦输入。  
- **Vim 模式（可选）**：`j/k` 导航，`H/L` 跳转回合，`h/l` 折叠，`i`/`Tab`/`Space` 聚焦输入。  

开启 Vim：在 `~/.grok/config.toml` 设置：

```toml
[ui]
vim_mode = true
```

或运行时 `/vim-mode`。

> 单字母与 `Shift+字母` 的回滚导航需要 `vim_mode = true`。方向键、`Tab`、`Esc`、`PageUp/Down`、`Ctrl+字母` 在两种模式下通常都可用。

## 回滚导航（焦点在回滚）

| 键 | 简易模式 | 作用 |
|----|----------|------|
| `j` | `↓` | 下一项 |
| `k` | `↑` | 上一项 |
| `⇧L` | `Shift+→` | 下一用户回合 |
| `⇧H` | `Shift+←` | 上一用户回合 |
| `g` / `⇧G` | | 顶部 / 底部 |
| `PageUp` / `PageDown` | | 上/下翻页 |
| `Ctrl+U` / `Ctrl+D` | | 半页上/下 |

## 显示控制

| 键 | 作用 |
|----|------|
| `h` / `l`（Vim） | 折叠 / 展开 |
| `e` | 切换折叠 |
| `⇧E` | 全部展开/折叠 |
| `Ctrl+E` | 展开/折叠全部思考块 |
| `r` | 原始 markdown 切换 |

## 通用

| 键 | 作用 |
|----|------|
| `Esc` | 取消 / 关闭菜单 |
| `Ctrl+C` | 中断（视上下文） |
| `Enter` | 发送（或菜单确认） |
| `/` | 斜杠命令 |
| `@` | 文件引用 |

更完整的表格请对照上游英文版或本汉化仓库持续补全。主题与折叠行为见 [配置](05-configuration.md)。
