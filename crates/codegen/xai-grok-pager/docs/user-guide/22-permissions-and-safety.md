# 权限与安全

## 权限模式

| 模式 | 含义 |
|------|------|
| Ask | 工具操作前询问（常见默认） |
| Auto | 模型分类安全工具；危险仍可能询问 |
| Always approve | 跳过几乎所有权限提示（危险） |

设置：`/settings` → 代理与授权 → 权限模式。

## 记住授权

开启「记住工具授权」后，权限菜单出现「始终允许…」，可减少重复询问。需重启生效。

## 提示选项（汉化示例）

- 是  
- 是，继续  
- 始终允许：…  
- 否，并告诉 Grok 换种做法  
- 是，且不再询问任何操作（始终批准模式）  

## 安全建议

1. 日常用 **Ask**，不要默认 Always approve  
2. 只批准你理解的命令  
3. 用 hooks 限制危险 git/网络操作  
4. 敏感目录配合 sandbox  
5. 不要把 API Key 写进仓库  

## 与计划模式

计划模式限制可编辑路径；权限模式限制是否弹窗。二者叠加使用更安全。
