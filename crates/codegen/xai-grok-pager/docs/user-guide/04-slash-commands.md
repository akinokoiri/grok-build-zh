# 斜杠命令

在输入框键入 `/` 可打开命令列表并自动完成。

命令来源：

- **Shell 内置**：后端 agent 处理  
- **Pager 内置**：TUI 前端处理  
- **Skills**：`SKILL.md` 安装后也会出现在列表中  

---

## 会话

| 命令 | 说明 |
|------|------|
| `/new`（别名 `/clear`） | 新会话，清空当前对话 |
| `/resume` | 打开会话选择器加载历史 |
| `/compact [说明]` | 压缩上下文；可说明要保留的内容 |
| `/context` | 查看上下文占用与统计 |
| `/session-info` | 会话详情（模型、回合、用量） |
| `/fork` | 分叉当前会话 |
| `/rewind` | 回退到更早回合 |
| `/copy [n\|路径]` | 复制最近回复；可写文件（SSH 友好） |

上下文约 85% 时会自动压缩（`[session] auto_compact_threshold_percent` 可配）。

---

## 模型与模式

| 命令 | 说明 |
|------|------|
| `/model` | 切换模型 |
| `/plan` | 进入计划模式 |
| `/view-plan` | 查看已有计划 |
| `/vim-mode` | 切换 Vim 导航 |
| `/compact-mode` | 紧凑显示 |

---

## 设置与扩展

| 命令 | 说明 |
|------|------|
| `/settings` | 设置面板 |
| `/theme` | 主题 |
| `/mcp` | MCP 服务器 |
| `/skills` | 技能 |
| `/plugins` | 插件 |
| `/hooks` | 钩子 |
| `/memory` 相关 | 跨会话记忆（见记忆文档） |
| `/help` / 文档入口 | 打开用户指南 |

具体子命令与参数以当前版本自动完成菜单为准；上游可能新增命令。
