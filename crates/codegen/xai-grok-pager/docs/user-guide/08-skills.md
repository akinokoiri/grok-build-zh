# 技能（Skills）

Skill 是可复用的提示/工作流包，通常以 `SKILL.md` 描述，安装后可作为斜杠命令触发。

## 位置

- 用户级：`~/.grok/skills/`  
- 项目级：仓库内 skills 目录（若支持）  
- 捆绑技能：安装包内置  

## SKILL.md 要点

- 名称与描述  
- 触发时机 / 参数  
- 给代理的详细说明  

## 使用

输入 `/` 可在列表中看到技能命令。创建与规范见上游 skills 文档；汉化仓库 [TRANSLATING](https://github.com/ivan6232/grok-build-zh/blob/zh-CN/docs/zh/TRANSLATING.md) 不改变技能格式。
